# Contributing to MetroMate

Thanks for your interest in improving MetroMate!

## Before contributing

- Read the README and understand that the current station data is fictional.
- Create an issue describing the bug or improvement.
- Keep accessibility and passenger safety in mind.
- Do not add real station directions unless the data has been verified from an authoritative source.

## Development workflow

1. Fork the repository.
2. Create a branch: `git switch -c feature/your-feature`
3. Make a focused change.
4. Test the application locally.
5. Commit with a clear message.
6. Open a pull request describing the change and how you tested it.

## Good first contributions

- Improve mobile layout.
- Add tests for route preferences.
- Review translations with fluent speakers.
- Add voice guidance.
- Improve keyboard navigation and screen-reader labels.
